# 在庫更新の操作区分 — 誰が・いつ・何をするか(2026-09-18 整理)

ChatGPT 指示(2026-09-17): 「今回限りの操作／VBA を更新するときだけの操作／毎回の在庫更新で必要な操作／Claude Code 側で自動化できる操作」を分け、
Excel 上でしかできないことと英樹本人がしなければならないことを区別する。英樹の操作は技術的に必要な最小限にまとめる。

## 0. 前提(守ること)

- Excel の操作は `excel_bridge.py` 経由のみ: 対象はフルパスで特定／開いた直後と保存直前に再確認／自分が開いたブックだけ保存・閉じる／
  対象や同名ブックが人に開かれていれば**何もしない**／quit・全ブック保存はしない(2026-09-12 の事故対策)
- 本番(`SourceData/楽天在庫金額集計ツール_v1.0.xlsm`・`SourceData/Import/`)を変える前に一意な名前でバックアップ
- 自動実行で本番を動かすときは、Excel に**他のブックが1つでも開いていれば止める**(人が作業中の可能性)。`run_stock_tool.py --target production` はこの規則を組み込み済み

## 2. VBA を更新するときだけ必要な操作(V-2/V-3/V-4 …)

| 操作 | 誰が | 制約(なぜ人がやるのか) |
|---|---|---|
| VBE で Module_Rakuten_Tool を削除 → 新しい `.bas` をインポート → 保存(コピー検証で1回・本番で1回) | **英樹** | Mac Excel には VBA プロジェクトを外部から書き換える口が無い(AppleScript は `run VB macro` しかできず、`VBProject.VBComponents.Import` を呼ぶ「起動用マクロ」も存在しない。`vbaProject.bin` を直接書き換えるのは壊す危険が大きく採用しない)。VBE をGUI自動操作(System Events)するのは不安定でアクセシビリティ許可も要るため採用しない |

## 4. Claude Code 側で自動化できる操作(まとめ)

- できる(済み): Import 生成、差分・削除記録、Python 予測、在庫ツールの 読込→集計→保存(V-4 以降・excel_bridge 経由)、検証、バックアップ、確認リスト、サマリー再生成
- できない(人): RMS/Amazon のダウンロード(アカウント操作)、VBA モジュールの入替(VBE)、サンドボックスの初回許可、予期しないダイアログの解消、原価・誤記・商品番号の判断

## 5. 自動実行の承認と条件(ChatGPT 2026-09-19)

- 本番の 読込→集計→保存 を Claude Code の自動実行で行う運用を**承認**(コピー検証 PASS が前提。既承認の 9/16 資料・反映範囲は変えない)
- 維持: フルパスによる対象確認・実行前バックアップ・人が開いていたブックを保存/閉じない
- 条件1: **タイムアウトを「停止」とみなさない**。Excel 側の実行状態(応答・対象ブックが開いたまま・ダイアログ・ファイル更新)を確認するまで、
  再実行も手動操作への切替もしない。終了確認ができなければその時点で状況を報告する → `excel_bridge.excel_state()` / `run_stock_tool.py` の TIMEOUT 分岐
- 条件2: マクロの OK 応答に加え、**保存後に再読込して** 集計値・識別子・原価未登録件数・ファイルサイズ(・読込/集計日時)を検証する。
  不一致なら成功扱いにせず後続を止める → `run_stock_tool.py verify_after()`(終了コード 1)＋ `verify_v4_copy.py 1/2/prodrun`
- 対象・入力資料が変わっていなければ、既承認範囲の本番自動実行に再承認は不要。今後の通常更新も自動実行を基本とし、
  未掲載商品の削除・原価変更・曖昧な商品対応など**新しい判断が必要な項目だけ**英樹へ確認する

## 6. 自動実行の仕組みと止まり方

- `run_stock_tool.py --target copy|production` → `excel_bridge.run_macros(path, ['AutoImport', 'AutoAggregate'])` →
  AppleScript `run VB macro "'ブック名'!AutoImport"`。VBA 側は `g_silent=True` で MsgBox を出さず結果を文字列で返す
- 戻り値が `OK:` で始まらなければ保存しない。対象ブックは**勝手に閉じない**(`close_on_error=False`)。`excel_state()` で
  Excel が応答し・対象が開いたまま・ダイアログが無いと確認できたときだけ `close_without_saving()` で自分が開いた対象を閉じる
- timeout は「停止」ではない。状態を報告して止まる(再実行しない)
- ボタン操作(CsvImport / RunAggregation)の動きは従来どおり(MsgBox あり)
